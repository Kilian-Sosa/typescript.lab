THE PROBLEM

Find the longest valid window

Given an array of event identifiers and an integer k, find the longest contiguous window containing at most k distinct identifiers.

Return the start index and exclusive end index. If multiple windows have the same maximum length, return the earliest one.

Function signatureTYPESCRIPT 
function longestWindow(
  events: string[],
  k: number
): { start: number; endExclusive: number }
Example
INPUTevents = ["A","B","A","C","B","B"]k = 2
EXPECTED OUTPUT{ start: 0, endExclusive: 3 }
Constraints & edge cases
  • At most k distinct event identifiers.
  • Indices are zero-based; end is exclusive.
  • For an empty array or k ≤ 0, return {0, 0}.
  • Prefer the earliest valid window on ties.
